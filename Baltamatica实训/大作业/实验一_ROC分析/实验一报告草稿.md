# 实验一：自定义 ROC 分析类的设计与实现

## 1. 实验目的

本实验在北太天元中设计并实现 `MyROC` 类，根据二分类问题的真实标签和预测得分计算 ROC 曲线与 AUC。通过本实验掌握类、属性和方法的基本使用，并理解重复得分、极端阈值以及梯形积分在 ROC 分析中的作用。

## 2. 类设计

`MyROC` 类包含五个属性：

- `Labels`：真实类别标签。
- `Scores`：分类器输出的正类得分。
- `FPR`：不同阈值下的假阳性率。
- `TPR`：不同阈值下的真阳性率。
- `AUC`：ROC 曲线下面积。

类中包含四个方法：

- `MyROC(labels, scores)`：检查输入合法性，保存数据并自动计算 ROC 和 AUC。
- `computeROC(obj)`：计算 ROC 曲线点。
- `computeAUC(obj)`：使用 `trapz` 计算 AUC。
- `plotROC(obj, plotTitle)`：绘制 ROC 曲线并设置数据集标题。

属性使用 `SetAccess = private`，外部程序可以读取结果，但不能直接修改对象内部属性。

构造函数先将输入转换为列向量，检查 `labels` 和 `scores` 的元素数量
是否一致，并检查标签是否全部为 `0` 或 `1`。检查通过后，输入分别
存入 `Labels` 和 `Scores` 属性。

## 3. ROC 计算方法

程序先将得分按降序排列，并同步调整标签顺序：

```matlab
[sortedScores, sortIndex] = sort(scores, 'descend');
sortedLabels = labels(sortIndex);
```

随后找出每个相同得分组的结束位置：

```matlab
scoreChangeIndex = [find(diff(sortedScores) ~= 0); numel(sortedScores)];
```

相同得分样本必须作为一组处理，否则 ROC 曲线会受到同分样本内部顺序的影响。最终版使用累计和直接得到每个位置的 TP 和 FP：

```matlab
cumulativeTP = cumsum(sortedLabels == 1);
cumulativeFP = cumsum(sortedLabels == 0);
tpr = [0; cumulativeTP(scoreChangeIndex) / positiveCount; 1];
fpr = [0; cumulativeFP(scoreChangeIndex) / negativeCount; 1];
```

向量首尾的 `0` 和 `1` 分别对应：

```text
+Inf -> 全部判为负类 -> (0,0)
-Inf -> 全部判为正类 -> (1,1)
```

该方法的主要时间开销是排序，复杂度约为 `O(n log n)`，比逐阈值反复扫描全部样本更高效。

## 4. AUC 计算

得到 `FPR` 和 `TPR` 后，程序按照题目要求使用梯形积分：

```matlab
obj.AUC = trapz(obj.FPR, obj.TPR);
```

AUC 越接近 1，分类器区分正负样本的能力越强；AUC 接近 0.5 时，分类效果接近随机分类器。

## 5. 绘图方法

程序使用蓝色实线绘制 ROC 曲线，使用红色虚线绘制随机分类器参考线，同时设置坐标名称、数据集标题、图例、网格、坐标范围和 AUC 标注。

最终绘图使用北太天元默认字体、默认字号和默认线宽，避免连续生成多张图时出现响应缓慢。主要代码为：

```matlab
figure;
plot(obj.FPR, obj.TPR, 'b-');
hold on;
plot([0 1], [0 1], 'r--');
hold off;

xlabel('False Positive Rate');
ylabel('True Positive Rate');
title(plotTitle);
legend('ROC Curve', 'Random Classifier');
text(0.62, 0.12, ['AUC = ' num2str(obj.AUC, '%.4f')]);
grid on;
axis([0 1 0 1]);
```

## 6. 测试程序

`testMyROC.m` 连续加载以下三个题目指定的数据文件：

- `data1.mat`
- `data2.mat`
- `data3.mat`

每个文件包含 `labels` 和 `scores`。主程序为每组数据创建 `MyROC` 对象，输出样本数、ROC 点数和 AUC，并生成一个独立图窗。

当前北太天元 GUI 可以正常绘图，但安装版本中 `saveas` 未定义。因此最终代码不进行自动保存，运行结束后从三个图窗中依次手动保存：

```text
data1_ROC.png
data2_ROC.png
data3_ROC.png
```

代码中不使用 MATLAB、外部工具箱、`onCleanup`、SVG 导出或额外的两两 AUC 计算。

## 7. 实际运行结果

北太天元命令窗口输出如下：

```text
实验一：自定义ROC分析类测试
----------------------------------------
程序将连续绘制3张ROC图，完成后请逐张保存。
data1.mat: 样本数 = 100, ROC点数 = 102, AUC = 1.0000
data2.mat: 样本数 = 200, ROC点数 = 194, AUC = 0.9464
data3.mat: 样本数 = 2000, ROC点数 = 1750, AUC = 0.9040
----------------------------------------
测试完成，请将3个图窗依次保存为data1_ROC.png、data2_ROC.png和data3_ROC.png。
```

结果汇总：

| 数据集 | 样本数 | ROC 点数 | AUC |
|---|---:|---:|---:|
| `data1.mat` | 100 | 102 | 1.0000 |
| `data2.mat` | 200 | 194 | 0.9464 |
| `data3.mat` | 2000 | 1750 | 0.9040 |

`data1.mat` 的 AUC 为 1，说明该数据中的正负样本完全可分。`data2.mat` 和 `data3.mat` 的 AUC 均超过 0.9，说明分类器具有较强的区分能力。

ROC 点数等于唯一得分数量加两个极端阈值点。处理完最低得分组后通常已经到达 `(1,1)`，再加入 `-Inf` 端点会产生一个重复终点，但横坐标增量为零，因此不会改变 AUC。

## 8. 实验总结

本实验完成了 `MyROC` 类的设计，实现了 ROC 曲线点计算、AUC 梯形积分和结果绘图。算法通过排序、同分组和累计和稳定处理重复得分，并显式包含 `(0,0)` 和 `(1,1)` 两个极端状态。最终代码能够在北太天元图形界面中快速处理三个指定数据集，并生成符合题目要求的 ROC 图。
