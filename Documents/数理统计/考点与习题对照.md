### 考点 3：UMVUE + C-R 下界（Lehmann-Scheffé 定理）

> 核心套路：找完备充分统计量 → 无偏估计 → L-S 定理得 UMVUE → 与 C-R 下界比较。

**★ 习题二 #13** — $\{1,\ldots,N\}$ 离散均匀：$X_{(n)}$ 完备充分 → $N$ 的 UMVUE
**★ 习题二 #18** — $B(1,\theta)$：$\theta^m$ 和 $P(\sum_{i=1}^m X_i = k)$ 的 UMVUE（与期末 Q3 同分布族！）
**★ 习题二 #24** — $N(0,\sigma^2)$：$\sigma$、$3\sigma^4$ 的 UMVUE + 有效估计 + 相合估计
**习题二 #15** — 两样本正态：$\sigma^2$ 及 $\frac{\mu_1-\mu_2}{\sigma}$ 的 UMVUE

**★ 习题二 #21** — Exp(λ) 中 $P(X \le t_0) = 1-e^{-\lambda t_0}$ 的 UMVUE

### 考点 7：似然函数（截断 / 分类数据 / EM 背景）

> 两卷都出在最后一题，15 分。考的是"写出观测数据似然"和"写出完整数据似然"。
> 不要求 EM 迭代，只要求写似然函数。

这两题本质是同一道题，属于理解型题目——把线性回归 + 正态误差 + 二值化观测串起来。需要理解：

- 观测数据似然：$P(Y_i|X_i) = [\Phi((25-β_0-β_1X_i)/σ)]^{1-Y_i} [1-\Phi(...)]^{Y_i}$
- 完整数据似然：$Z_i|X_i \sim N(β_0+β_1X_i, σ^2)$ 的联合密度

**无直接对应习题**，但习题二 #54（Logistic 回归 MLE）和习题二 #29（样本相关系数分布）提供了相关背景。

## 四、备考策略建议

1. **抽样分布**：重点做习题一 #35、#29、#62，掌握"标准化正态 / √(χ²/df) → t" 和 "两独立 χ² 的比 → F" 两种模式。

2. **点估计**：位移指数族（$e^{-(x-\theta)}$）和均匀分布是最高频考题。习题二 #39 和 #9 必须熟练掌握。注意：MLE 求导不可行时用次序统计量；无偏修正用期望计算；相合性用切比雪夫或均方收敛。

3. **UMVUE**：核心是 Lehmann-Scheffé 定理。熟练套路：找完备充分统计量 → 构造无偏估计 → 用 C-R 下界判断有效性。习题二 #18、#24 是标杆。

4. **假设检验**：LRT 是重中之重（近两年都考）。关键是写出 $H_0$ 和 $H_1$ 下的 MLE，构造 $\lambda = L_0/L_1$，化简后找出等价检验统计量及其分布。习题三 #26、#23、#30 优先做。

5. **置信区间**：$\sigma$ 的区间必会。$\mu$ 的区间、两样本均值差、方差比的区间也应掌握。
