## 试卷一：2023—2024学年第二学期《数理统计》期末考试题

---

### 1. 求统计量 $Z$ 的分布

$X_1,\ldots,X_{25} \stackrel{iid}{\sim} N(\mu, \sigma^2)$。

$Y_1 = \frac{1}{10}\sum_{i=1}^{10} X_i \sim N(\mu, \sigma^2/10)$，$Y_2 = \frac{1}{15}\sum_{i=11}^{25} X_i \sim N(\mu, \sigma^2/15)$。

$Y_1$ 与 $Y_2$ 独立 $\Rightarrow Y_1 - Y_2 \sim N\!\left(0,\; \sigma^2\left(\tfrac{1}{10} + \tfrac{1}{15}\right)\right) = N(0, \sigma^2/6)$。

故 $\frac{\sqrt{6}(Y_1 - Y_2)}{\sigma} \sim N(0,1)$。

$S^2 = \frac{1}{14}\sum_{i=11}^{25}(X_i - Y_2)^2$，有 $\frac{14S^2}{\sigma^2} \sim \chi^2(14)$，且 $S^2$ 与 $Y_1, Y_2$ 均独立。

因此

$$Z = \frac{\sqrt{6}(Y_1 - Y_2)}{S} = \frac{\frac{\sqrt{6}(Y_1-Y_2)}{\sigma}}{\sqrt{\frac{S^2}{\sigma^2}}} = \frac{N(0,1)}{\sqrt{\chi^2(14)/14}} \sim \mathbf{t(14)}.$$

### 2. $f(x;\theta) = e^{-(x-\theta)}I(x>\theta)$

**(a)** $X = \theta + Y$，$Y \sim \text{Exp}(1)$，$E[X] = \theta+1$。

矩估计：$\bar{X} = \theta + 1 \;\Rightarrow\; \hat{\theta}_M = \bar{X} - 1$。

极大似然：$L(\theta) = e^{-\sum(X_i-\theta)}I(X_{(1)} > \theta)$ 关于 $\theta$ 单调递增，故 $\hat{\theta}_L = X_{(1)}$。

**(b)** $E[\hat{\theta}_M] = E[\bar{X}] - 1 = (\theta+1)-1 = \theta$，**无偏**。

$X_{(1)} = \theta + \min_i Y_i$，$\min_i Y_i \sim \text{Exp}(n)$，$E[X_{(1)}] = \theta + 1/n \neq \theta$，**有偏**。修正：$\hat{\theta}_L^* = X_{(1)} - 1/n$（无偏）。

**(c)** $\text{Var}(\hat{\theta}_M) = \text{Var}(\bar{X}) = 1/n \to 0$，由切比雪夫不等式：

$$P(|\hat{\theta}_M - \theta| \geq \varepsilon) \leq \frac{\text{Var}(\hat{\theta}_M)}{\varepsilon^2} = \frac{1}{n\varepsilon^2} \to 0.$$

对 $\hat{\theta}_L$：$E[(\hat{\theta}_L - \theta)^2] = \text{Var}(X_{(1)}) + \text{bias}^2 = \frac{1}{n^2} + \frac{1}{n^2} = \frac{2}{n^2}$，

$$P(|\hat{\theta}_L - \theta| \geq \varepsilon) \leq \frac{E[(\hat{\theta}_L-\theta)^2]}{\varepsilon^2} = \frac{2}{n^2\varepsilon^2} \to 0.$$

两估计均相合。

### 3. $X_i \stackrel{iid}{\sim} B(1,\theta)$，求 $\theta(1-\theta)$ 的 UMVUE

**(a)** $T = \sum X_i \sim B(n,\theta)$ 是完备充分统计量。

$E[T] = n\theta$，$E[T^2] = n\theta + n(n-1)\theta^2$。

$$E[T(n-T)] = nE[T] - E[T^2] = n^2\theta - n\theta - n(n-1)\theta^2 = n(n-1)\theta(1-\theta).$$

故 $E\!\left[\frac{T(n-T)}{n(n-1)}\right] = \theta(1-\theta)$。

由 Lehmann-Scheffé 定理，**UMVUE 为** $T(\mathbf{X}) = \dfrac{\bar{X}(1-\bar{X})}{1 - 1/n} = \dfrac{T(n-T)}{n(n-1)}$。

**(b)** Fisher 信息：$I_n(\theta) = \frac{n}{\theta(1-\theta)}$。$g(\theta)=\theta(1-\theta)$，$g'(\theta)=1-2\theta$。

$$\text{CRLB} = \frac{[g'(\theta)]^2}{I_n(\theta)} = \frac{(1-2\theta)^2\theta(1-\theta)}{n}.$$

$T(\mathbf{X})$ 是 $T$ 的二次函数，而得分函数是 $T$ 的线性函数。UMVUE 达到 CRLB 当且仅当它是得分函数的线性函数，故一般 **达不到**（仅当 $\theta = 1/2$ 时 CRLB = 0，平凡成立）。

### 4. $\sigma$ 的 $1-\alpha$ 双侧置信区间

枢轴量：$\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$。

$$P\!\left(\chi^2_{1-\alpha/2}(n-1) \leq \frac{(n-1)S^2}{\sigma^2} \leq \chi^2_{\alpha/2}(n-1)\right) = 1-\alpha.$$

解得 $\sigma$ 的 $1-\alpha$ 置信区间：

$$\left[\;\sqrt{\frac{(n-1)S^2}{\chi^2_{\alpha/2}(n-1)}},\quad \sqrt{\frac{(n-1)S^2}{\chi^2_{1-\alpha/2}(n-1)}}\;\right].$$

---

### 5. 似然比检验 $H_0: \sigma_1^2 = 2\sigma_2^2 \leftrightarrow H_1: \sigma_1^2 \neq 2\sigma_2^2$

$X_i \sim N(0,\sigma_1^2)$，$Y_j \sim N(0,\sigma_2^2)$。

令 $\sigma_2^2 = \sigma^2$，则 $H_0$ 下 $\sigma_1^2 = 2\sigma^2$。

$H_1$ 下 MLE：$\hat{\sigma}_1^2 = \frac{1}{n}\sum X_i^2$，$\hat{\sigma}_2^2 = \frac{1}{m}\sum Y_j^2$。

$H_0$ 下 MLE：$\hat{\sigma}^2 = \frac{\sum X_i^2/2 + \sum Y_j^2}{n+m}$。

似然比：

$$\Lambda = \frac{L_0}{L_1} = 2^{-n/2} \cdot \frac{(\hat{\sigma}^2)^{-(n+m)/2}}{(\hat{\sigma}_1^2)^{-n/2}(\hat{\sigma}_2^2)^{-m/2}}.$$

注意 $H_0$ 下 $\sum X_i^2/(2\sigma^2) \sim \chi^2(n)$，$\sum Y_j^2/\sigma^2 \sim \chi^2(m)$，独立。故

$$F = \frac{\sum X_i^2/(2n)}{\sum Y_j^2/m} = \frac{m\sum X_i^2}{2n\sum Y_j^2} \sim F(n, m).$$

$-2\ln\Lambda$ 是 $F$ 的单调函数，否定域为 $F$ 过大或过小。

**检验水平 $\alpha$ 的否定域：**

$$F \leq F_{1-\alpha/2}(n, m) \quad \text{或} \quad F \geq F_{\alpha/2}(n, m).$$

### 6. 均值检验

$n = 36$，$\bar{x} = 66.5$，$s = 15$。$H_0: \mu = 70$ vs $H_1: \mu \neq 70$。

$$t = \frac{66.5 - 70}{15/\sqrt{36}} = \frac{-3.5}{2.5} = -1.4.$$

$|t| = 1.4 < t_{0.025}(35) = 2.0301$，**不拒绝 $H_0$**。

不能认为全体考生的平均成绩与 70 分有显著差异。

### 7. EM 算法中的似然函数

**(a)** 观测数据 $(Y_i, X_i)$ 的似然（$Y_i = I(Z_i \geq 25)$）：

$$P(Y_i=0 \mid X_i) = \Phi\!\left(\frac{25 - \beta_0 - \beta_1 X_i}{\sigma}\right),$$

$$P(Y_i=1 \mid X_i) = 1 - \Phi\!\left(\frac{25 - \beta_0 - \beta_1 X_i}{\sigma}\right).$$

$$L_{\text{obs}} = \prod_{i=1}^n \left[\Phi\!\left(\frac{25 - \beta_0 - \beta_1 X_i}{\sigma}\right)\right]^{1-Y_i} \cdot \left[1 - \Phi\!\left(\frac{25 - \beta_0 - \beta_1 X_i}{\sigma}\right)\right]^{Y_i} \cdot g(X_i).$$

**(b)** 完整数据 $(Z_i, X_i)$ 的似然：

$$L_{\text{comp}} = \prod_{i=1}^n \left[\frac{1}{\sqrt{2\pi}\sigma}\exp\!\left(-\frac{(Z_i - \beta_0 - \beta_1 X_i)^2}{2\sigma^2}\right) \cdot g(X_i)\right].$$

## 试卷二：武汉大学 2025—2026 学年第二学期《数理统计》测试

---

### 1. 求 $Z$ 的分布

$\bar{X} \sim N(\mu, \sigma^2/n)$，$X_{n+1} \sim N(\mu, \sigma^2)$，二者独立。

$X_{n+1} - \bar{X} \sim N\!\left(0,\; \sigma^2\!\left(1+\frac{1}{n}\right)\right) = N(0, \sigma^2\frac{n+1}{n})$。

故 $\frac{X_{n+1} - \bar{X}}{\sigma\sqrt{\frac{n+1}{n}}} \sim N(0,1)$。

$\frac{(n-1)S_n^2}{\sigma^2} \sim \chi^2(n-1)$，与 $X_{n+1}$、$\bar{X}$ 独立。

$$Z = \sqrt{\frac{n}{n+1}}\frac{X_{n+1} - \bar{X}}{S_n} = \frac{\frac{X_{n+1} - \bar{X}}{\sigma\sqrt{\frac{n+1}{n}}}}{\sqrt{S_n^2 / \sigma^2}} \sim \mathbf{t(n-1)}.$$

---

### 2. $f(x) = 3e^{-3(x-\theta)}I(x>\theta)$，$\theta>0$

$X = \theta + Y$，$Y \sim \text{Exp}(3)$，$E[Y]=1/3$，$\text{Var}(Y)=1/9$。

**(a)** $E[X] = \theta + 1/3$。矩估计：$\bar{X} = \theta + 1/3 \;\Rightarrow\; \hat{\theta}_1 = \bar{X} - 1/3$。

MLE：$L(\theta) = 3^n e^{-3\sum(X_i-\theta)}I(X_{(1)} > \theta)$ 关于 $\theta$ 递增，$\hat{\theta}_2 = X_{(1)}$。

**(b)** $E[\hat{\theta}_1] = (\theta+1/3)-1/3 = \theta$，**无偏**。

$\hat{\theta}_2 = \theta + \min_i Y_i$，$\min_i Y_i \sim \text{Exp}(3n)$，$E[\hat{\theta}_2] = \theta + \frac{1}{3n}$，**有偏**。

**(c)** $\hat{\theta}_1$ 已无偏。$\hat{\theta}_2^* = X_{(1)} - \frac{1}{3n}$（无偏）。

$$\text{Var}(\hat{\theta}_1) = \text{Var}(\bar{X}) = \frac{\text{Var}(X)}{n} = \frac{1/9}{n} = \frac{1}{9n}.$$

$$\text{Var}(\hat{\theta}_2^*) = \text{Var}(X_{(1)}) = \text{Var}(\min_i Y_i) = \frac{1}{9n^2}.$$

$n>1$ 时 $\frac{1}{9n^2} < \frac{1}{9n}$，故 **$\hat{\theta}_2^*$ 更有效**。

**(d)** $E[\hat{\theta}_1] = \theta$（无偏），$\text{Var}(\hat{\theta}_1) = \frac{1}{9n}$。由切比雪夫：

$$P(|\hat{\theta}_1 - \theta| \geq 0.1) \leq \frac{\text{Var}(\hat{\theta}_1)}{0.1^2} = \frac{1/9n}{0.01} = \frac{100}{9n}.$$

---

### 3. $X_i \stackrel{iid}{\sim} N(\theta, 1)$，求 $\theta^2$ 的 UMVUE

**(a)** $\bar{X} \sim N(\theta, 1/n)$ 是完备充分统计量。

$E[\bar{X}^2] = \theta^2 + 1/n$，故 $E[\bar{X}^2 - 1/n] = \theta^2$。

由 Lehmann-Scheffé，**UMVUE 为** $T(\mathbf{X}) = \bar{X}^2 - 1/n$。

**(b)** Fisher 信息 $I_n(\theta) = n$。$g(\theta) = \theta^2$，$g'(\theta) = 2\theta$。

$$\text{CRLB} = \frac{(2\theta)^2}{n} = \frac{4\theta^2}{n}.$$

计算 $\text{Var}(T)$：令 $U = \sqrt{n}\bar{X} \sim N(\sqrt{n}\theta, 1)$。$\bar{X}^2 = U^2/n$。

$$\text{Var}(U^2) = \text{Var}((U-\sqrt{n}\theta + \sqrt{n}\theta)^2) = \text{Var}(W^2 + 2\sqrt{n}\theta W + n\theta^2),$$

其中 $W \sim N(0,1)$。$\text{Var}(W^2)=2$，$\text{Var}(2\sqrt{n}\theta W)=4n\theta^2$，$\text{Cov}(W^2,W)=E[W^3]=0$。

故 $\text{Var}(U^2) = 2 + 4n\theta^2$。

$$\text{Var}(T) = \frac{\text{Var}(U^2)}{n^2} = \frac{2}{n^2} + \frac{4\theta^2}{n} = \text{CRLB} + \frac{2}{n^2} > \text{CRLB}.$$

**未达到 C-R 下界**（$\frac{2}{n^2} > 0$ 对所有 $\theta$ 成立）。

---

### 4. $\sigma$ 的 $1-\alpha$ 双侧置信区间

同试卷一第 4 题：

$$\left[\;\sqrt{\frac{(n-1)S^2}{\chi^2_{\alpha/2}(n-1)}},\quad \sqrt{\frac{(n-1)S^2}{\chi^2_{1-\alpha/2}(n-1)}}\;\right].$$

### 5. 似然比检验 $H_0: \theta = 0 \leftrightarrow H_1: \theta \neq 0$

$f(x;\theta) = e^{-(x-\theta)}I(x \geq \theta)$。MLE：$\hat{\theta} = X_{(1)}$。

$H_1$ 下：$L_1 = e^{-\sum X_i + nX_{(1)}}I(X_{(1)} \geq X_{(1)}) = e^{-\sum X_i + nX_{(1)}}$。

$H_0$ 下：若 $X_{(1)} \geq 0$，$L_0 = e^{-\sum X_i}$；若 $X_{(1)} < 0$，$L_0 = 0$。

$$\lambda = \frac{L_0}{L_1} = \begin{cases} e^{-nX_{(1)}}, & X_{(1)} \geq 0, \\ 0, & X_{(1)} < 0. \end{cases}$$

$\lambda$ 关于 $X_{(1)}$ 单调递减（$X_{(1)} \geq 0$ 时）。否定域形式：$X_{(1)} > c$。

$H_0$ 下：$X_i \sim \text{Exp}(1)$，$nX_{(1)} \sim \text{Exp}(1)$。

$$P_{H_0}(X_{(1)} > c) = e^{-nc} = \alpha \;\Rightarrow\; c = -\frac{\ln\alpha}{n}.$$

**检验水平 $\alpha$ 的拒绝域：$X_{(1)} > -\dfrac{\ln\alpha}{n}$，或等价地 $2nX_{(1)} > \chi^2_{\alpha}(2)$。**

---

### 6. 同试卷一第 7 题

**(a)** 观测数据 $(Y_i, X_i)$ 似然：

$$L_{\text{obs}} = \prod_{i=1}^n \left[\Phi\!\left(\frac{25 - \beta_0 - \beta_1 X_i}{\sigma}\right)\right]^{1-Y_i} \cdot \left[1 - \Phi\!\left(\frac{25 - \beta_0 - \beta_1 X_i}{\sigma}\right)\right]^{Y_i} \cdot g(X_i).$$

**(b)** 完整数据 $(Z_i, X_i)$ 似然：

$$L_{\text{comp}} = \left(\frac{1}{\sqrt{2\pi}\sigma}\right)^n \exp\!\left(-\frac{1}{2\sigma^2}\sum_{i=1}^n (Z_i - \beta_0 - \beta_1 X_i)^2\right) \cdot \prod_{i=1}^n g(X_i).$$
