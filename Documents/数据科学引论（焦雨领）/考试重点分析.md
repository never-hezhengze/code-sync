## 二、考点分布深度分析

### 第一梯队：极高概率考点（真题反复出现，课件有完整推导过程）

以下内容课件中有**完整的定义→引理→推导→结论链条**，且真题直接考察过。**必须能独立完成证明**。

1. **Lasso 的完整理论**（真题第 5 题，20 分）
   - 课件中有：$\ell_1$ 约束的几何解释 → 受限特征值条件（RE condition）→ 误差界的完整推导
   - 需要掌握：RE 条件的定义、为什么需要它、推导中每一步的依据
   - 课件行数：约 356-396 行

2. **SVD 及其在数据科学中的应用**（真题第 1 题，20 分）
   - 课件中有：SVD 定义 → 变分刻画 → Moore-Penrose 伪逆 → Eckart-Young 最优低秩近似 → 线性自编码器的最优解
   - 需要掌握：SVD 的三种等价定义（特别是变分刻画）、最优低秩近似的证明思路
   - 课件行数：约 3620-3754 行

3. **次微分 / 近端算子的基本理论与计算**（真题第 2 题，20 分）
   - 课件中有：次梯度定义 → Fermat 法则 → 常见函数的次微分计算（$\ell_1$, $\ell_2$, $\ell_\infty$, 核范数）→ 近端算子 → 软阈值 → 近端梯度下降
   - 需要掌握：Fermat 法则的证明、软阈值算子的推导、近端梯度下降的收敛性证明
   - 课件行数：约 4049-4108 行

4. **集中不等式**（真题第 3 题，20 分）
   - 课件中有：sub-Gaussian 定义/性质 → Hoeffding 不等式 → Bernstein 不等式 → McDiarmid 不等式（含完整证明 + 鞅差分解）
   - 需要掌握：McDiarmid 不等式的完整证明（五个步骤的鞅差分解）、Hoeffding 不等式的条件和使用
   - 课件行数：约 4641-4920 行

5. **监督学习基础框架**（真题第 4 题，10 分）
   - 课件中有：风险最小化 → 目标函数 $f^*$ 的定义 → 回归和分类下 $f^*$ 的闭式解 →
     ERM → 超额风险 → 误差三分量（$E_{gen}, E_{app}, E_{opt}$）
   - 需要掌握：$f^*(x) = \mathbb{E}[Y|X=x]$（回归）和 $f^*(x) = \arg\max_k P(Y=k|X=x)$（分类）的推导
   - 课件行数：约 29-61 行（反复出现多次）

### 第二梯队：高频考点（课件花费大量篇幅，理论体系完整，真题虽未直接出现但极易组合出题）

6. **梯度下降 / SGD / 近端梯度下降的收敛性分析**
   - 课件中有：GD 对光滑凸函数的次线性收敛 → PL 条件下的线性收敛 → 强凸情况 → SGD 收敛 → SVRG 方差缩减 → 近端梯度下降
   - 课件篇幅：约 200+ 行（1075-1337 行附近）
   - 典型考题形式：证明 GD 的 $O(1/t)$ 收敛率、推导 SGD 的基本不等式、SVRG 的方差缩减原理

7. **凸优化理论**
   - 课件中有：凸集/凸函数 → 一阶/二阶条件 → 强凸性 → Lipschitz 梯度 → 共轭函数（Fenchel）→ KKT 条件 → Lagrange 对偶 → 强对偶的 Slater 条件
   - 课件篇幅：约 300+ 行（3888-4286 行）
   - 典型考题形式：证明某个函数是凸的、KKT 条件的应用、对偶问题的推导

8. **极小极大下界**
   - 课件中有：非参数回归的极小极大下界 → Fano 方法 → KL 散度的张量化和上界 → 最优速率
   - 课件篇幅：约 80+ 行（1367-1501 行）
   - 典型考题形式：推导非参数回归的极小极大下界（$n^{-2\alpha/(2\alpha+d)}$）

9. **经验风险最小化（ERM）的泛化误差界**
   - 课件中有：误差三分量 → 统计误差（$E_{sta}$）→ 覆盖数 → Rademacher 复杂度 → Dudley 熵公式 → 对称化
   - 课件篇幅：约 150+ 行（482-733 行）
   - 典型考题形式：界定 ERM 的泛化误差、Rademacher 复杂度的基本不等式

10. **岭回归 / 普通最小二乘的偏差-方差分解**
    - 课件中有：OLS 估计误差 → Ridge 的偏差和方差 → 正则化参数 $\lambda$ 的选择 → 高概率界
    - 课件篇幅：约 60+ 行（145-265 行）
    - 典型考题形式：推导 Ridge 的偏差和方差、分析 $\lambda$ 的影响

### 第三梯队：中等概率考点（课件有但理论链条稍短，或偏实际应用）

11. **SVM 与核方法**
    - 课件中有：最大间隔分类器 → Hinge 损失 → 对偶问题 → KKT → 支持向量 →
      核技巧 → RKHS → 表示定理
    - 可能与凸优化/对偶理论结合出题
    - 课件篇幅：约 80+ 行（1653-1860 行）

12. **表示学习 / 自监督学习**
    - 课件中有：充分降维 → 迁移学习 → SimCLR → 数据增强 → 聚类辅助分类
    - 更偏概念/综述，证明题出题概率相对较低

13. **分类校准理论**
    - 课件中有：$\ell_{0-1}$ 损失的凸松弛 → 分类校准的定义 → 凸损失是分类校准的充要条件
    - 课件篇幅：约 40+ 行（1515-1557 行）

14. **近似误差与神经网络逼近理论**
    - 课件中有：Kolmogorov-Arnold 定理 → Hölder 类上的神经网络逼近 → 维度灾难 → Telgarsky 锯齿函数构造
    - 证明极其复杂，可能是"陈述结果"而非"完整证明"的题型

### 第四梯队：较低概率考点（课件中篇幅大但偏前沿/数值实验/开放性内容）

15. **深度生成模型 / GAN / 扩散模型 / Langevin 采样**
    - 课件中篇幅很大（约 300+ 行），但集中在数值实验和前沿理论

16. **Schrödinger Bridge / Föllmer 流 / 一步采样**
    - 非常前沿，更偏研究介绍性质

## 三、应试策略建议

基于以上分析，备考优先顺序建议如下：

1. **最高优先级（必须能独立写出完整证明）**：
   - Lasso + RE 条件的误差界
   - SVD 的定义、变分刻画和应用（特别是最优低秩近似）
   - Fermat 法则、软阈值算子、近端算子
   - McDiarmid 不等式的证明（鞅差分解五步法）
   - 监督学习框架（$f^*$ 的闭式解推导）

2. **高优先级（理解核心思路，能写关键步骤）**：
   - GD 的 $O(1/t)$ 收敛性
   - 凸函数的一阶/二阶条件
   - 极小极大下界的推导框架（Fano 方法）
   - ERM 的误差三分量和泛化误差界

3. **中等优先级（掌握概念和主要结论）**：
   - Ridge 回归的偏差-方差分解
   - SVM 对偶问题的推导
   - KKT 条件的应用
   - 集中不等式的使用条件

4. **了解即可（概念层面）**：
   - 表示学习、SSL、扩散模型、GAN 等前沿话题
   - 分类校准的定义和条件

## 四、真题风格总结

- 全是**证明题**或**推导题**（100%），没有计算题、选择题或代码题
- 题目直接来自课件中的**定理证明**或**核心推导链**
- 分值集中在 20 分/题，说明每道题都期望考生写出**完整的、有逻辑链条的证明**
- 第 6 题为开放性建议题（10 分），属于送分题
- 考试时间 150 分钟，6 道题，平均每道题 25 分钟——需要非常熟练
