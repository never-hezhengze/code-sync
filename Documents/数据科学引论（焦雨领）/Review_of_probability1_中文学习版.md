## 第 3 页：条件独立不等于独立

这一页讲一个很重要的反直觉现象：

**两个随机变量本来独立，但在给定某个条件之后，可能变得不独立。**

课件中的结构是：

```text
X -> Z <- Y
```

这叫 **collider structure（碰撞结构）**。意思是 `Z` 同时受到 `X` 和 `Y` 的影响。

例子：

- `X`：数学能力是否强；
- `Y`：音乐能力是否强；
- `Z`：是否被顶尖项目录取；
- 规则：只要数学或音乐有一个强，就录取，即 `Z = 1 iff X = 1 or Y = 1`。

在总体人群中，数学能力和音乐能力可以互相独立：

```text
X perp Y
```

但如果我们只看“已经被录取的人”，即给定 `Z = 1`，情况就变了：

- 如果知道某人数学不强，即 `X = 0`；
- 又知道他已经被录取，即 `Z = 1`；
- 那就能推出他的音乐能力一定强，即 `Y = 1`。

所以在条件 `Z = 1` 下，`X` 和 `Y` 不再独立：

```text
X 不独立于 Y | Z = 1
```

**核心结论：**

独立不推出条件独立。特别是当我们条件化在一个 collider 上时，变量之间可能产生新的依赖关系。

## 第 4 页：集合极限与 Borel-Cantelli 引理

这一页先定义事件列的极限。

如果事件越来越大：

```text
A1 ⊂ A2 ⊂ A3 ⊂ ...
```

记作：

```text
An ↑ A, 其中 A = ∪ An
```

如果事件越来越小：

```text
A1 ⊃ A2 ⊃ A3 ⊃ ...
```

记作：

```text
An ↓ A, 其中 A = ∩ An
```

对于一般的事件列 `{An}`，定义：

```text
lim sup An = ∩_{n=1}^∞ ∪_{k=n}^∞ Ak
lim inf An = ∪_{n=1}^∞ ∩_{k=n}^∞ Ak
```

直观理解：

- `lim sup An` 表示事件 `An` **无穷多次发生**，也写作 `An i.o.`，其中 `i.o.` 是 infinitely often；
- `lim inf An` 表示从某个时刻开始，`An` **最终一直发生**。

并且有：

```text
lim inf An ⊂ lim sup An
```

因为“最终一直发生”当然蕴含“无穷多次发生”。

**Borel-Cantelli 引理：**

1. 如果

   ```text
   ∑ P(An) < ∞
   ```

   那么

   ```text
   P(An i.o.) = 0
   ```

   含义：如果事件发生概率的总和有限，那么这些事件无穷多次发生的概率为 0。

2. 如果 `{An}` 相互独立，并且

   ```text
   ∑ P(An) = ∞
   ```

   那么

   ```text
   P(An i.o.) = 1
   ```

   含义：在相互独立时，如果概率总和发散，那么这些事件无穷多次发生的概率为 1。

注意这里第二条要求 **mutually independent（相互独立）**，不是只要求 pairwise independent（两两独立）。

## 第 5 页：第一 Borel-Cantelli 引理证明

要证明：

```text
如果 ∑ P(An) < ∞，则 P(An i.o.) = 0
```

先令：

```text
Bm = ∪_{k=m}^∞ Ak
```

`Bm` 表示“从第 `m` 项开始，至少有一个事件发生”。

随着 `m` 增大，`Bm` 越来越小：

```text
B1 ⊃ B2 ⊃ B3 ⊃ ...
```

而：

```text
lim sup An = ∩_{m=1}^∞ Bm
```

利用概率的连续性：

```text
P(lim sup An) = lim_{m→∞} P(Bm)
```

又因为：

```text
P(Bm) = P(∪_{k=m}^∞ Ak) ≤ ∑_{k=m}^∞ P(Ak)
```

如果总和 `∑ P(Ak)` 收敛，那么尾和：

```text
∑_{k=m}^∞ P(Ak)
```

会随着 `m -> ∞` 收敛到 0。

所以：

```text
P(lim sup An) = 0
```

也就是：

```text
P(An i.o.) = 0
```

**一句话理解：**

如果所有事件概率加起来都有限，那么后面剩下的概率质量会越来越小，小到不足以支持“无穷多次发生”。

## 第 6 页：第二 Borel-Cantelli 引理证明

要证明：

```text
如果 {An} 相互独立且 ∑ P(An) = ∞，则 P(An i.o.) = 1
```

目标事件是：

```text
lim sup An = ∩_{m=1}^∞ ∪_{k=m}^∞ Ak
```

直接处理并集不方便，因为独立性通常对交集更好用。于是看它的补集。

定义：

```text
Cm = ∩_{k=m}^∞ Ac_k
```

`Cm` 表示“从第 `m` 项开始，所有 `Ak` 都不发生”。

由于事件相互独立：

```text
P(Cm) = P(∩_{k=m}^∞ Ac_k)
      = ∏_{k=m}^∞ P(Ac_k)
      = ∏_{k=m}^∞ (1 - P(Ak))
```

利用不等式：

```text
1 - x ≤ exp(-x)
```

得到：

```text
P(Cm) ≤ exp(-∑_{k=m}^∞ P(Ak))
```

因为 `∑ P(Ak) = ∞`，所以从任意 `m` 开始的尾和仍然发散，因此：

```text
exp(-∞) = 0
```

也就是：

```text
P(Cm) = 0
```

最后得到：

```text
P(lim sup An) = 1
```

**一句话理解：**

如果独立事件的总概率无限大，那么“从某一刻开始再也不发生”这件事概率为 0，因此它们会无穷多次发生，概率为 1。

## 第 7 页：Jensen 不等式的应用

这一页证明一个常用结论：

如果：

```text
0 < p ≤ q ≤ ∞
```

那么：

```text
||X||_Lp ≤ ||X||_Lq
```

意思是：在概率空间上，`Lq` 范数控制 `Lp` 范数。`q` 越大，对随机变量尾部的要求越强。

### 情况一：q = ∞

`L∞` 范数是本质上界：

```text
||X||_L∞ = ess sup |X|
```

由于：

```text
|X| ≤ ess sup |X|
```

所以：

```text
(E|X|^p)^{1/p} ≤ ||X||_L∞
```

即：

```text
||X||_Lp ≤ ||X||_L∞
```

### 情况二：q < ∞

令：

```text
φ(t) = t^{q/p}
```

因为 `q/p ≥ 1`，所以 `φ` 是凸函数。对随机变量 `|X|^p` 使用 Jensen 不等式：

```text
(E|X|^p)^{q/p} ≤ E(|X|^q)
```

也就是：

```text
||X||_Lp^q ≤ ||X||_Lq^q
```

所以：

```text
||X||_Lp ≤ ||X||_Lq
```

## 第 8 页：随机变量的分布与 push-forward measure

设随机变量：

```text
X : Ω -> R
```

定义在概率空间：

```text
(Ω, F, P)
```

上。它会在实数空间 `(R, B(R))` 上诱导出一个概率测度，叫做 **push-forward measure（推前测度）**，记作：

```text
PX
```

定义为：

```text
PX(A) = P({ω : X(ω) ∈ A}) = P(X^{-1}(A))
```

其中 `A` 是实数上的 Borel 集。

这其实就是随机变量 `X` 的 **law/distribution（分布）**。

如果 `f : R -> R`，那么下面几种写法表示同一件事：

```text
∫_Ω f(X(ω)) dP
= ∫_R f(x) dPX
= ∫_R f(x) PX(dx)
```

**直观理解：**

原来我们是在样本空间 `Ω` 上对 `f(X(ω))` 积分。通过 `X` 的分布 `PX`，可以把积分搬到实数轴上。

## 第 9 页：用尾概率表示期望

这一页给出非常重要的公式。

如果 `X ≥ 0`，则：

```text
E[X] = ∫_0^∞ P(X > t) dt
```

意思是：非负随机变量的期望可以看成它的尾概率曲线下面积。

对于一般随机变量，有：

```text
E[X] = ∫_0^∞ (1 - F(x)) dx - ∫_{-∞}^0 F(x) dx
```

其中 `F(x) = P(X ≤ x)` 是分布函数。

绝对值期望为：

```text
E[|X|] = ∫_0^∞ (1 - F(x)) dx + ∫_{-∞}^0 F(x) dx
```

证明思路：

对非负随机变量：

```text
x = ∫_0^x 1 dt
```

于是：

```text
E[X] = ∫_0^∞ x μ(dx)
     = ∫_0^∞ ∫_0^x 1 dt μ(dx)
```

用 Fubini 定理交换积分顺序，就得到：

```text
E[X] = ∫_0^∞ P(X > t) dt
```

对于一般 `X`，分解成正部和负部：

```text
X+ = max(X, 0)
X- = max(-X, 0)
X = X+ - X-
|X| = X+ + X-
```

再分别使用非负情形的结论。

## 第 10 页：尾概率方法的推广

同样的方法可以用于更复杂的期望，比如：

```text
E[X^p], E[e^{λX}]
```

如果 `X ≥ 0`，则：

```text
E[X^p] = p ∫_0^∞ t^{p-1} P(X > t) dt
```

这个公式在证明矩是否有限时特别好用。

例如，如果直接计算 `E[X^p]` 很困难，但我们能证明尾概率满足：

```text
P(X > t) ≤ c t^{-α}
```

且：

```text
α > p
```

那么：

```text
E[X^p] ≤ cp ∫_0^∞ t^{p-1-α} dt
```

由于指数满足：

```text
p - 1 - α < -1
```

所以积分在无穷远处收敛，从而可以推出：

```text
E[X^p] < ∞
```

**学习重点：**

尾概率衰减越快，随机变量的高阶矩越容易有限。这个思想在概率不等式、泛化误差、随机过程里都很常见。

## 第 11-12 页：条件期望中的信息粗细

这两页内容重复，讨论下面三个命题：

1. `E[X | Y = y] = E[X | g(Y) = g(y)]`
2. `E[X | Y] = E[X | g(Y)]`
3. `E[X | Y] = E[X | Y, g(Y)]`

答案是：

```text
第 3 个为真；第 1、2 个一般为假。
```

原因是：如果 `g` 不是单射，那么 `g(Y)` 会压缩 `Y` 的信息。

例如：

```text
Y = 具体分数
g(Y) = 是否及格
```

知道“具体分数”比知道“是否及格”包含更多信息。

因此：

```text
E[X | Y]
```

是更细的条件期望，而：

```text
E[X | g(Y)]
```

是更粗的条件期望。

为什么第 3 个为真？

因为如果已经知道了 `Y`，那么 `g(Y)` 是由 `Y` 决定的，并没有提供额外信息：

```text
σ(Y, g(Y)) = σ(Y)
```

所以：

```text
E[X | Y, g(Y)] = E[X | Y]
```

## 第 14 页：可测映射、生成 σ-代数与独立性

### 可测映射

设：

```text
f : (Ω, F) -> (R, B(R))
```

如果对任意 Borel 集 `A ∈ B(R)`，都有：

```text
f^{-1}(A) ∈ F
```

则称 `f` 是可测的。

注意这里的 `f^{-1}` 是 **pre-image（原像）**，不是反函数。

随机变量本质上就是从样本空间到实数空间的可测映射。

### 生成 σ-代数

对于随机向量：

```text
X = (X1, X2, ..., Xn)
```

`σ(X)` 表示由这些随机变量生成的最小 σ-代数，也就是让所有 `Xi` 都可测所需的最少信息。

可以写作：

```text
σ(X) = σ(X^{-1}(B(R)))
```

直观理解：`σ(X)` 包含了所有能通过观察 `X` 判断的事件。

### 独立 σ-代数与独立随机变量

一列子 σ-代数 `{Fn}` 被称为独立，如果对任意 `An ∈ Fn`，都有：

```text
P(∩ An) = ∏ P(An)
```

随机变量 `{Xn}` 相互独立，定义为它们生成的 σ-代数 `{σ(Xn)}` 相互独立。

这说明在严谨概率论里，“随机变量独立”其实是“它们携带的信息相互独立”。

## 第 15 页：如何验证可测性

问题：给定：

```text
f : (Ω, F) -> (R, B(R))
```

如何验证 `f` 可测？

答案：只需要验证对所有 `t ∈ R`，

```text
{x ∈ Ω : f(x) ≤ t} ∈ F
```

原因是：

```text
B(R) = σ({(-∞, t] : t ∈ R})
```

也就是说，实数上的 Borel σ-代数由所有半无限区间 `(-∞, t]` 生成。

如果这些生成集合的原像都在 `F` 中，那么所有 Borel 集的原像也都在 `F` 中，因为原像运算保持补集和可数并。

更高层次的观点是：

很多概率论命题只要在一个生成类上验证，就能推广到整个 σ-代数。这背后常用的是：

- monotone class theorem（单调类定理）
- λ-π theorem（λ-π 定理）

这些工具常用于证明可测性、独立性、测度相等等结论。

## 第 16 页：可测函数和 σ-代数的关系

这一页的核心思想是：

**σ-代数越丰富，能定义的可测函数越复杂。**

先看示性函数：

```text
1_A 可测 ⇔ A ∈ F
```

因为 `1_A` 的取值只有 0 和 1，所以只要看：

```text
{1_A ≤ t}
```

不同 `t` 下得到的集合是：

```text
t < 0      -> ∅
0 ≤ t < 1  -> Ac
t ≥ 1      -> Ω
```

因此可测性等价于 `A ∈ F`。

几个例子：

1. 如果：

   ```text
   F = {∅, Ω}
   ```

   这是最小 σ-代数。此时可测函数只能是常数函数。因为这个 σ-代数无法区分任何非平凡事件。

2. 如果：

   ```text
   F = {∅, A, Ac, Ω}
   ```

   那么可测函数只能在 `A` 和 `Ac` 上分别取常数，即：

   ```text
   f = a 1_A + b 1_Ac
   ```

3. 如果：

   ```text
   F = σ(A1, A2, ..., An)
   ```

   且 `A1, ..., An` 构成 `Ω` 的一个有限划分，那么可测函数形如：

   ```text
   f = ∑ ai 1_Ai
   ```

**结论：**

σ-代数可以理解成“你能观察到的信息”。信息越细，可测函数就可以越复杂。

## 第 17 页：随机过程中的 filtration

在随机过程中，我们通常考虑：

```text
(Xt)_{t≥0}
```

并配套一个 filtration（滤过）：

```text
(Ft)_{t≥0}
```

它满足：

```text
Fs ⊂ Ft,  当 s < t
```

也就是说，时间越往后，信息越多。

整个概率空间可以写成：

```text
(Ω, F, (Ft)t, P)
```

通常要求：

```text
Xt ∈ Ft
```

也就是说，`Xt` 是关于 `Ft` 可测的。

直观理解：在时间 `t`，我们只能使用截至 `t` 时刻的信息来知道 `Xt`。随着 `Ft` 增大，随机变量可以依赖的信息越来越多，所以可以变得越来越复杂。

## 第 18 页：用 Radon-Nikodym 定理定义条件期望

这一页给出条件期望的严格定义。

### Radon-Nikodym 导数

设 `(Ω, F, μ)` 是 σ-有限测度空间，`ν` 是符号测度，并且：

```text
ν ≪ μ
```

即 `ν` 关于 `μ` 绝对连续。

那么存在唯一的可测函数 `f`，使得：

```text
ν(A) = ∫_A f dμ
```

此时称：

```text
f = dν/dμ
```

为 Radon-Nikodym 导数。

### 条件期望定义

给定概率空间 `(Ω, F, P)`，随机变量 `X` 满足：

```text
E[|X|] < ∞
```

定义符号测度：

```text
ν(A) = ∫_A X dP
```

对任意 `A ∈ F`。

现在取子 σ-代数：

```text
G ⊂ F
```

把 `P` 和 `ν` 都限制在 `(Ω, G)` 上。由于：

```text
ν|G ≪ P|G
```

由 Radon-Nikodym 定理，存在唯一的 `G`-可测随机变量 `Y`，使得：

```text
Y = dν|G / dP|G
```

这个 `Y` 就定义为：

```text
E[X | G]
```

**直观理解：**

条件期望是在信息 `G` 下，对 `X` 做出的最佳平均描述。它必须只能使用 `G` 中的信息。

## 第 19 页：条件期望的两个定义条件

Radon-Nikodym 导数通常通过积分等式理解：

```text
对任意 A ∈ G，有 ∫_A X dP = ∫_A Y dP
```

其中：

```text
Y = E[X | G]
```

所以条件期望可以用两个条件刻画：

1. `E[X | G]` 是 `G`-可测的；
2. 对任意 `A ∈ G`，

   ```text
   ∫_A E[X | G] dP = ∫_A X dP
   ```

第一条说明：条件期望只能依赖 `G` 提供的信息。

第二条说明：在任何 `G` 能识别的事件上，条件期望和原随机变量的积分一致。

注意：

```text
E[X | G] ∈ G
```

意思是它关于 `G` 可测，而不是说它是 σ-代数里的一个集合。更严格地说，应理解为：

```text
E[X | G] is G-measurable
```

有了条件期望，就可以定义条件概率：

```text
P(A | G) = E[1_A | G]
```

## 第 20 页：和朴素条件期望的联系

我们平时写：

```text
E[X | Y]
```

严格地说是：

```text
E[X | σ(Y)]
```

因为条件期望真正条件化的是一个 σ-代数，也就是信息集合。

在适当条件下：

```text
E[X | Y = y]
```

可以看成函数：

```text
E[X | σ(Y)](y)
```

也就是说，条件期望本身是一个随机变量，或者可以理解成关于 `Y` 的函数。

**直观理解：**

条件在 `Y` 上，其实就是条件在“观察 `Y` 能得到的全部信息”上。

## 第 21 页：理解条件期望的两种方式

条件期望有两个重要直观理解：

1. **平均化理解**

   `E[X | G]` 是把更复杂的随机变量 `X`，在较小的信息结构 `G` 下做平均。

   换句话说：原来 `X` 可能依赖很多信息，但条件期望只允许依赖 `G` 的信息，于是它把 `G` 看不见的细节平均掉。

2. **正交投影理解**

   在 `L2(Ω, G, P)` 里，`E[X | G]` 可以看成把 `X` 投影到由 `G`-可测随机变量组成的子空间上。

   也就是说，它是只使用 `G` 信息时，对 `X` 的最佳平方误差近似。

这两个理解非常重要：

- 第一个帮助理解“信息变粗”；
- 第二个帮助理解机器学习、回归、鞅和随机过程中的投影思想。

## 第 22 页：结束页

这一页是 thank you。

本份 review 的主线可以概括为：

1. 条件化会改变独立关系，尤其要小心 collider；
2. `lim sup` 表示无穷多次发生，Borel-Cantelli 引理研究事件列长期行为；
3. Jensen 不等式可以比较不同 `Lp` 范数；
4. 期望可以用尾概率表示，这对证明矩有限非常有用；
5. 随机变量、分布、可测性、本质上都依赖 σ-代数；
6. 条件期望的严格定义是对较小信息 σ-代数的 Radon-Nikodym 导数；
7. 条件期望可以理解成“信息变粗后的平均”，也可以理解成 `L2` 空间里的正交投影。
