# 平推流反应器（PFR）数值模拟作业

## 一、作业背景与目的

平推流反应器（Plug Flow Reactor, PFR）是化工生产中常见的理想反应器模型。掌握其特征方程及参数影响规律，是反应工程学习的重要内容。

本作业旨在通过 AI 辅助编程（如 deepseek 等工具）生成 Python 代码，构建一个图形用户界面（GUI），动态模拟不同操作条件和反应特性下，反应物 A 在 PFR 中的浓度沿管长的分布及出口转化率。同时，通过撰写分析报告，加深对 PFR 性能方程的理解，并训练运用数值模拟解释工程问题的能力。

## 二、作业任务概述

**编程部分：** 利用 AI 工具生成 Python 代码，在 Python IDLE 中运行，生成一个 GUI 界面。界面中包含三个可调参数：物料的体积流量 \(v\) (L/s)、反应的速率常数 \(k\)、反应级数 \(n\) (\(n\) 可正、可负、可为零)。

**给定条件：**
- 入口浓度 \(C_{A0} = 1.0 \, \text{mol/L}\)。
- 反应器直径 \(D = 1.0 \, \text{dm}\)（即 10 cm），反应器总体积 \(V_{\text{total}} = 10 \, \text{L}\)。
- 恒温恒容系统，不可逆反应 \(A \rightarrow \) 产物。

**功能要求：**
当用户输入或修改上述三个参数并点击“计算”后，程序应绘制出反应物 A 浓度 \(C_A\) 沿反应器管长 \(L\) 的分布曲线（横坐标为管长，单位 dm），并同时显示出口转化率 \(X_A = (1 - C_{A,\text{exit}} / C_{A0}) \times 100\%\)。

**报告部分：** 撰写一份分析报告（PDF 格式），基于 PFR 的特征方程，详细讨论：
- 物料体积流量 \(v\)、速率常数 \(k\)、反应级数 \(n\) 的变化，如何影响浓度分布曲线的形状（整体上移/下移）？
- 这些参数的变化为何会导致出口转化率增大或减小？
- 报告中需结合数学表达式及模拟结果（可附不同参数下的截图）进行说明。

## 三、具体要求
