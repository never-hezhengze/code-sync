# 变量定义
## 1. 定义决策变量
- $P_t$ : 第t月的生产量  
- $H_t$ : 第t月的工人数  
- $E_t$ : 第t月新增的雇佣人数  
- $F_t$ : 第t月解雇的工人数  
- $I_t$ : 第t月末的库存量  
- $B_t$ : 第t月的缺货量  
- $O_t$ : 第t月的外包产量  
- $T_{nt}$ : 第t月的正常工作工时  
- $T_{ot}$ : 第t月的加班工作工时  
其中$t=1,2,3,4,5,6$
## 2. 其他变量
- 原材料成本 $c$ : 90/件  
- 人工工时 $th$ : 5小时/件  
- 产品单价 $w$ : 300/件  
- 正常时薪 $s_{nt}$ : 30元  
- 加班时薪 $s_{ot}$ : 40元  
- 外包成本 $o$ : 200元/件  
- 缺货成本 $b$ : 35元/件  
- 库存成本 $i$ : 15元/件  
- 雇佣成本 $E_c$ : 5000元/人  
- 解雇成本 $F_c$ : 8000元/人  
- 初始工人数 $H_0$ : 1000人  
- 初始库存 $I_0$ : 15000件  

**月需求预测（$D_t$）：**  
|    月份    |   1   |   2   |   3   |   4   |   5   |   6   |
| :--------: | :---: | :---: | :---: | :---: | :---: | :---: |
| 需求量预测 | 20000 | 40000 | 42000 | 35000 | 19000 | 18500 |
# 目标函数
## 最大化净利润
### 第t月的净利润计算:
$\text{净利润}=\text{总销售收入}-\text{总生产成本}-\text{人工成本}-\text{外包成本}-\text{缺货成本}-\text{库存成本}-\text{雇佣成本}-\text{解雇成本}$

即  
$\text{MAX }Z=\sum_{t=1}^6 \Bigg[
w\times (D_t-B_t)
-c\times P_t
-s_{nt}\times T_{nt}
-s_{ot}\times T_{ot}
-o\times O_t
-i\times I_t
-b\times B_t
-E_c\times E_t
-F_c\times F_t
\Bigg]$


# 约束条件
## （1） 库存平衡
对于每个月t，有以下等式成立：  
$$I_{t-1}+P_t+O_t-D_t+B_t=I_t$$
其中$D_t$是第t个月的需求量。
## （2） 生产能力与工时约束
- 生产量要满足人工工时约束  
  $$T_{nt}+T_{ot}=th\times P_t$$
- 工时约束
    $$T_{nt}=160\times H_t$$
    $$T_{ot}\leq20\times H_t$$
## （3） 工人数目约束
每月工人数目变化
$$H_t=H_{t-1}+E_t-F_t$$
## （4）库存与缺货的约束
结合实际情况，库存与缺货不可能同时不为0，即
$$I_t \times B_t = 0$$
## （5） 非负性约束
所有决策变量非负:  
$$P_t,H_t,E_t,F_t,I_t,B_t,O_t,T_{nt},T_{ot}\geq0$$  
并且工人数$H_t$和雇佣、解雇人数$E_t$、$F_t$要求是整数
## （6） 6月末库存要求
第6月结束时，要求库存不少于10000件：  
$$I_6\geq10000$$
# 代码实现
```lingo
model :

! 决策变量定义：;
! P(t): 生产量，O(t): 外包量，I(t): 库存量，B(t): 缺货量;
! H(t): 工人数，E(t): 雇佣人数，F(t): 解雇人数;
! Tn(t): 正常工时，To(t): 加班工时，S(t): 实际销售量;

sets :
t/1..6/: P, O, I, B, H, E, F, Tn, To, D, S;
endsets

! 参数定义;
w = 300;     ! 产品售价;
c = 90;      ! 原材料单价;
sn = 30;     ! 正常工时工资;
so = 40;     ! 加班工时工资;
oc = 200;    ! 外包成本;
ic = 15;     ! 库存成本;
bc = 35;     ! 缺货成本;
Ec = 5000;   ! 雇佣成本;
Fc = 8000;   ! 解雇成本;
th = 5;      ! 工时（每件）;

data :
D = 20000,40000,42000,35000,19000,18500;
enddata
I0 = 15000; ! 初始库存;
H0 = 1000;  ! 初始工人;

!目标函数;
max  =  @SUM (t(k):
(w * (D(k)-B(k)
- c * P(k)
- sn * Tn(k)
- so * To(k)
- oc * O(k)
- ic * I(k)
- bc * B(k)
- Ec * E(k)
- Fc * F(k))
);

!产能与工时约束;
@for (t(k): P(k) = (Tn(k) + To(k))/th;);
@for (t(k): Tn(k) = 160 * H(k););
@for (t(k): To(k) <= 20 * H(k););

!库存平衡;
@for (t(k) | k #GT# 1:
I(k) = I(k-1) + P(k) + O(k) - D(k) + B(k)
);
I(1) = I0 + P(1) + O(1) - D(1) + B(1);

!工人数目约束;
@for (t(k)|k #GT# 1: H(k) = H(k-1) + E(k) - F(k););
H(1) = H0 + E(1) - F(1);
I(6) >= 10000;

!非负性与整数约束;
@for (t(k):  @GIN (H(k)));
@for (t(k):  @GIN (E(k)));
@for (t(k):  @GIN (F(k)));
@for (t(k):  Tn(k) >= 0;);
@for (t(k):  To(k) >= 0;);
@for (t(k):  B(k) >= 0;);
@for (t(k):  P(k) >= 0;);
@for (t(k):  O(k) >= 0;);
@for (t(k):  I(k) >= 0;);
@for (t(k):  S(k) >= 0;);

end
```
