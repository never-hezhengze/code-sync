# 第十章作业
## 1. 构建该博弈的支付矩阵，找出纯策略纳什均衡点
### 支付矩阵：
| | B: 高价 (4500) | B: 中价 (3500) |
|:---:|:---:|:---:|
|A: 高价 (4000)  | (20, 25)  |  (-5, 30)
|A: 中价 (3000)  | (18, 10)  |  (15, 20)

### 纯策略纳什均衡点：
- 对于A：  
如果B选择高价，A选择高价可以得到更高的收益  
如果B选择中价，A选择中价可以得到更高的收益  
- 对于B：  
如果A选择高价，B选择中价可以得到更高的收益  
如果A选择中价，B选择中价可以得到更高的收益  
因此，在**双方都选择中价时**，A和B都没有改变策略的倾向，这是唯一的纯策略纳什均衡点。  
纯策略纳什均衡点：AB均选择中价，收益为（15，20）

## 2. 若政府推出“中端机型研发补贴5 亿元”政策，重新计算A 选择中价时的收益，分析均衡变化
### 新的支付矩阵：
| | B: 高价 (4500) | B: 中价 (3500) |
|:---:|:---:|:---:|
|A: 高价 (4000)  | (20, 25)  |  (-5, 35)|
|A: 中价 (3000)  | (23, 10)  |  (20, 25)|

### 重复上述分析：  
- 对于A：  
如果B选择高价，A选择高价可以得到更高的收益  
如果B选择中价，A选择中价可以得到更高的收益  
- 对于B：  
如果A选择高价，B选择中价可以得到更高的收益  
如果A选择中价，B选择中价可以得到更高的收益  
故在**A和B都选择中价时**，没有任何一方可以通过单方面更改策略达到更高的收益，此时达到纯策略纳什均衡点，收益为（20，25）

## 3. 讨论该模型中“高价策略”是否为占优策略，并解释囚徒困境现象的可能性。
### 占优策略：
**无论对手（其他玩家）选择什么策略，某一玩家选择该策略所获得的收益始终不低于（在某些情况下严格优于）其他任何策略。**  

在初始支付矩阵的条件下，结合对纯策略纳什均衡点的分析可以发现：对于A并没有占有策略，然而无论A选择高价或中价，B选择中价的收益始终不低于B选择高价时的收益。故对于B，**“高价策略”并非占优策略**。  

### 囚徒困境现象：
**双方各自选择对自己最有利的策略（背叛或坦白），导致集体利益受损（比合作更差的结果）**

在初始支付矩阵的条件下，当A和B都选择高价时，集体收益最大（20+25），此时达到帕累托最优。  
但是如果B这时选择更改策略为中价，B将得到更高的收益，而集体收益减小（30-5），帕累托最优时集体收益最大但很难自发实现，符合囚徒困境现象。
