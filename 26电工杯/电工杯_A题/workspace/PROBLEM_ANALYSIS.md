# 赛题分析报告：绿电直连型电氢氨园区优化运行

## 一、赛题概述

**本赛题共 5 个子问题。**

### 1.1 背景

随着"双碳"战略推进，绿电直连项目为新能源就近消纳提供新路径。本题研究一个"绿电—绿氢—绿氨"一体化绿电直连化工园区的优化运行问题。园区包含风电（40MW）、光伏（64MW）、碱性电解槽（ALKEL, 10MW）、质子交换膜电解槽（PEMEL, 10MW）、合成氨装置（0.75MW）、常规电负荷（峰值6MW）、储能设备，以及与外部电网的联网线路。

### 1.2 核心约束——绿电直连指标

- **自发自用比例** = (总用电量 − 上网电量 − 网购电量) / 新能源发电量 > 60%
- **绿电比例** = (新能源发电量 − 上网电量) / 总用电量 > 30%
- **上网电量比例** = 上网电量 / 新能源发电量 < 20%

### 1.3 关键参数

| 参数 | 值 |
|------|-----|
| 初始制氨产能 | 36 吨/日 |
| 碱性电解槽(ALKEL) | 10MW, 140 kg H₂/h, 效率70% |
| 质子交换膜电解槽(PEMEL) | 10MW, 160 kg H₂/h, 效率80% |
| 合成氨装置 | 0.75MW, 1.5 吨NH₃/h |
| 常规负荷峰值 | 6MW |
| 风电装机 | 40MW |
| 光伏装机 | 64MW |
| 分析时段 | 1小时 |
| 风电场景 | 6种 |
| 光伏场景 | 4种 |
| 组合场景 | 24种 |

### 1.4 产能扩容规则

制氨产能扩容时，配套电氢氨装置额定功率随产能规模**线性同步提升**。即72吨/日时，ALKEL=20MW, PEMEL=20MW, 合成氨=1.5MW。

## 二、子问题拆解

### 问题一：典型风光场景下运行指标分析（基础题）

**难度：简单**

**条件：** 电解槽与合成氨装置满负荷连续运行，不计功率损耗，36吨/日产能。

- **(1)** 计算并绘制典型日功率曲线（用电负荷、风光发电、购电、售电）
- **(2)** 计算日用电量、新能源发电量、网购/上网电量、三项绿电指标、吨氨成本；分析是否满足要求

**输入：** 附件1（常规负荷）、附件2（典型日风光）、附件5-8（技术经济参数）
**输出：** 功率曲线图、指标计算表
**方法：** 功率平衡计算 + 分时电价加权

### 问题二：离散制氨调节优化（中等）

**难度：中等**

**条件：** 产能72吨/日，产量从72→36吨/日（步长9吨），设备只有开/停两种状态。

- **(1)** 典型场景：每种产量下成本最低的生产时段安排 → 找最优日产量
- **(2)** 24种场景：最优时段安排、指标分布、全年统计（全满足/部分满足/全不满足）、吨氨成本曲线

**输入：** 附件1-8
**输出：** 各产量最优调度方案、绿电指标、吨氨成本分布
**方法：** 整数规划/枚举优化（24小时中选择开机时段，二进制决策变量）

### 问题三：连续制氨调节优化（中等偏难）

**难度：中等偏难**

**条件：** 产能72吨/日，产量72→36吨/日，功率连续可调（下限10%）。

- **(1)** 24种场景最优调度方案、绿电指标、吨氨成本、全年统计
- **(2)** 各场景运行分析
- **(3)** 与问题二对比分析

**输入：** 附件1-8
**输出：** 连续功率调度方案、对比分析
**方法：** 线性规划/非线性规划（连续决策变量，每小时功率水平）

### 问题四：离网运行 + 储能配置（困难）

**难度：困难**

**条件：** 离网运行，产能72吨/日，功率连续可调（下限10%）。

- **(1)** 无储能：各场景产量、吨氨成本、全年总量、产能利用率、最小风光装机
- **(2)** 有储能：最大弃电场景的储能最优配置、24场景调度方案
- **(3)** 离网 vs 联网经济性对比

**输入：** 附件1-8
**输出：** 储能配置方案、离网/联网对比
**方法：** 约束优化 + 储能调度模型 + 经济性分析

### 问题五：政策分析（开放题）

**难度：简单（定性分析）**

分析绿电园区容量渗透率提高对电力系统的影响（≥3种利弊），提出政策建议。

**方法：** 文献综述 + 定性/半定量分析

### 子问题依赖关系

```
问题一（基础） → 问题二（离散优化，扩容） → 问题三（连续优化，对比问题二）
                                                    ↓
                                              问题四（离网+储能）
                                                    ↓
                                              问题五（政策分析）
```

### 3.6 关键发现

1. **问题一初步估算**：36吨/日满负荷时，日总用电 558.72 MWh，典型日新能源发电 603.45 MWh，新能源发电量略大于用电量，但时序不匹配会导致同时存在购电和售电。
2. **72吨/日扩容后**：日总用电约 1056.72 MWh，远超多数场景发电量（平均 475.98 MWh），需要大量购电。
3. **场景差异极大**：最大发电场景（876.92 MWh）是最小场景（169.94 MWh）的5倍以上，调度策略需因场景而异。
4. **光伏波动最大**：光伏4种场景发电量从 509.44 到 20.48 MWh，差距25倍。

## 五、假设敏感性预检

### 5.1 模糊表述及解释

**歧义1：** "制氢耗电量 50 kWh/kg（未考虑效率）"
- 解释A：实际制氢耗电 = 50/效率，即 ALKEL 实际耗 50/0.7=71.4 kWh/kg，PEMEL 耗 50/0.8=62.5 kWh/kg
- 解释B：50 kWh/kg 是理论值，实际耗电就是设备额定功率除以产氢速率（ALKEL: 10000/140=71.4, PEMEL: 10000/160=62.5）
- **选择：解释B**。因为题目已给出额定功率和产氢速率，直接用即可。"未考虑效率"是说明50是理论值，实际值已体现在功率/产量比中。

**歧义2：** "合成氨装置投资成本 60000 元/kgH₂"
- 解释A：合成氨装置的投资成本按其处理的氢气量计算
- 解释B：可能是排版错误，应为 60000 元/kW 或其他单位
- **选择：解释A**。按题目原文使用，合成氨装置投资与其氢处理能力挂钩。

**歧义3：** "产能扩容时配套装置额定功率线性同步提升"
- 解释A：72吨/日时所有设备功率翻倍（ALKEL=20MW, PEMEL=20MW, NH3=1.5MW）
- 解释B：只有制氢氨设备翻倍，风光装机不变
- **选择：解释B**。题目说"配套电氢氨装置"线性提升，风光装机容量在后续问题中未提及变化（问题四才讨论最小装机）。

**歧义4：** "电氢氨装置只有全额开机和停机两种运行方式"（问题二）
- 解释A：ALKEL、PEMEL、合成氨三者同时开/停，作为一个整体
- 解释B：三者可以独立开停
- **选择：解释A**。题目说"电氢氨装置"作为整体，且制氢是为制氨服务，逻辑上应同步。

### 5.2 问题递进性预判

- **问题一**（36吨/日满负荷）→ 基准：计算指标，可能部分不满足（因时序不匹配）
- **问题二**（72吨/日离散调节）→ 通过选择开机时段匹配风光出力，降低购电成本，改善绿电指标
- **问题三**（72吨/日连续调节）→ 比问题二更灵活，成本应更低，指标应更好
- **问题四**（离网+储能）→ 无购电，完全依赖风光，产量受限但加储能后改善
- **问题五**（政策）→ 定性分析

递进逻辑清晰：满负荷→离散优化→连续优化→离网+储能，灵活性递增。

## 六、建模思路规划

### 问题一：功率平衡计算

**方法：** 直接计算（无优化）

核心公式：
$$P_{buy}(t) = \max(0, P_{load}(t) + P_{ALKEL} + P_{PEMEL} + P_{NH3} - P_{wind}(t) - P_{pv}(t))$$
$$P_{sell}(t) = \max(0, P_{wind}(t) + P_{pv}(t) - P_{load}(t) - P_{ALKEL} - P_{PEMEL} - P_{NH3})$$

吨氨成本计算：
$$C_{ton} = \frac{\text{购电成本} + \text{风光度电成本} + \text{运维成本} - \text{售电收入}}{Q_{NH3}}$$

### 问题二：整数规划（离散调度）

**方法：** 0-1整数规划 / 枚举法

决策变量：$u(t) \in \{0, 1\}$，$t = 1, ..., 24$

约束：
- $\sum_{t=1}^{24} u(t) = \text{所需开机小时数}$（由日产量决定）
- 绿电直连三项指标约束（软约束，用于分析）

目标：最小化日运行成本（购电成本 + 风光成本 + 运维 − 售电收入）

由于24小时选k个时段开机，组合数 $C(24,k)$ 可枚举（最大 $C(24,12)=2704156$），可用枚举+剪枝或整数规划求解。

### 问题三：线性规划（连续调度）

**方法：** 线性规划（LP）

决策变量：$\alpha(t) \in [0.1, 1]$，$t = 1, ..., 24$

约束：
- $\sum_{t=1}^{24} \alpha(t) \cdot Q_{max}/24 = Q_{target}$（日产量约束）
- $\alpha(t) \geq 0.1$（下限约束）
- 功率平衡

目标：最小化日运行成本

### 问题四：离网优化 + 储能配置

**方法：** 
- (1) 约束优化（LP）：离网条件下最大化产量
- (2) 储能配置：混合整数规划或参数扫描
- (3) 经济性对比：年化成本分析

离网约束：$P_{buy}(t) = 0, P_{sell}(t) = 0$
$$P_{ALKEL}(t) + P_{PEMEL}(t) + P_{NH3}(t) + P_{load}(t) + P_{sto,c}(t) \leq P_{wind}(t) + P_{pv}(t) + P_{sto,d}(t)$$

储能状态方程：
$$E_{sto}(t+1) = E_{sto}(t)(1-0.002) + \eta_c P_{sto,c}(t) - P_{sto,d}(t)/\eta_d$$

### 问题五：定性分析

**方法：** 文献综述 + 系统分析

利弊分析维度：电力系统稳定性、调峰调频、电网投资、碳减排、产业链等。
