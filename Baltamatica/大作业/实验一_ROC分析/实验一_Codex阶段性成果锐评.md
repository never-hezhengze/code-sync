# 实验一阶段性成果复核摘要

## 一、复核结论

当前实验一代码已经整理为北太天元提交版，主程序可以在北太天元字符前端运行，完成 `data1.mat`、`data2.mat`、`data3.mat` 和 `tie_test` 的 ROC 数值计算与 AUC 验证。

代码不再依赖其它软件或外部工具箱函数。AUC 的独立验证使用本实验自带的 `pairwiseAUC.m` 完成。

## 二、已采纳的改进

- `computeROC()` 已从逐阈值扫描改为排序后按同分组增量累计，计算效率更高。
- 重复得分样本会被作为同一组处理，避免同分样本内部顺序影响 ROC 结果。
- `tie_test` 已改为“重复得分 + 仍有区分力”的测试场景，AUC 为 0.7222。
- 单类标签直接报错，因为只有正类或只有负类时 ROC 和 AUC 无定义。
- 输入检查使用 `if + error`，兼容北太天元。
- `pairwiseAUC.m` 独立保存，避免依赖脚本局部函数。
- 主程序会检测图形函数是否存在；北太天元字符前端不提供图形函数时，自动跳过图像保存，只输出数值结果。

## 三、最终验证结果

北太天元字符前端运行结果如下：

```text
data1.mat: AUC = 1.0000, Pairwise AUC = 1.000000
data2.mat: AUC = 0.9464, Pairwise AUC = 0.946400
data3.mat: AUC = 0.9040, Pairwise AUC = 0.903970
tie_test: AUC = 0.7222, Pairwise AUC = 0.722222
```

`MyROC` 与 `pairwiseAUC` 的差异均为浮点误差量级，说明实现结果可信。
