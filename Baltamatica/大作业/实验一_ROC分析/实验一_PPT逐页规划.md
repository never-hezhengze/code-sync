## 第 3 页：ROC 与 AUC 原理

### 页面标题

ROC 曲线与 AUC

### 页面内容

页面左侧放三个公式：

```text
TPR = TP / P
FPR = FP / N
AUC = ROC 曲线下面积
```

页面右侧放简要解释：

- 横轴 `FPR`：负类被误判为正类的比例。
- 纵轴 `TPR`：正类被正确识别的比例。
- 红色对角线：随机分类器。
- 曲线越靠近左上角，分类器越好。

### 建议素材

可使用 `results/data2_ROC.png` 作为背景较淡的示例图，或者单独放在右下角。

### 本页重点

只讲清楚坐标和 AUC 的意义，不展开混淆矩阵全部细节。

### 讲述口径

“ROC 曲线观察不同阈值下真正率和假正率的变化。AUC 用一个面积概括整条曲线，越接近 1，说明正负样本的区分效果越好。”

## 第 5 页：构造函数

### 页面标题

保存数据并自动计算

### 页面内容

贴构造函数完整代码：

```matlab
function obj = MyROC(labels, scores)
    labels = labels(:);
    scores = scores(:);
    if numel(labels) ~= numel(scores)
        error('labels and scores must have the same number of elements.');
    end
    if any((labels ~= 0) & (labels ~= 1))
        error('labels must contain only 0 and 1.');
    end
    obj.Labels = labels;
    obj.Scores = scores;
    obj = obj.computeROC();
    obj = obj.computeAUC();
end
```

配三条解释：

- `(:)` 将行向量和列向量统一成列向量。
- 检查标签数和得分数是否一致。
- 检查标签是否全部为 `0` 或 `1`。
- 检查通过后，将输入保存到 `Labels` 和 `Scores` 属性。
- 创建对象后自动得到 `FPR`、`TPR` 和 `AUC`。

### 本页重点

说明主程序为什么只需一行就能完成计算。

### 讲述口径

“构造函数先统一数据形状，然后自动完成 ROC 和 AUC 计算。主程序创建对象后，就可以直接读取结果或绘图。”

## 第 6 页：ROC 算法思路

### 页面标题

排序、同分组与累计和

### 页面内容

建议制作横向流程：

```text
Scores 降序排序
        ->
找到每个同分组的结束位置
        ->
累计正类数 TP 和负类数 FP
        ->
只在组末计算 TPR 和 FPR
        ->
加入起点和终点
```

下方放复杂度对比：

| 方法 | 主要操作 | 复杂度 |
|---|---|---|
| 逐阈值扫描 | 每个阈值重新检查全部样本 | 接近 `O(n^2)` |
| 当前方法 | 排序后累计并取组末位置 | 约 `O(n log n)` |

### 本页重点

这是算法讲解的核心页。强调“同分一起处理”和“累计和替代循环”。

### 讲述口径

“如果每个阈值都重新扫描全部样本，样本较多时会很慢。我先排序，再用累计和一次得到 TP 和 FP，并且只在相同得分组的末尾记录 ROC 点。”

## 第 7 页：computeROC 关键代码

### 页面标题

`computeROC()` 关键实现

### 页面内容

建议贴这一段：

```matlab
[sortedScores, sortIndex] = sort(scores, 'descend');
sortedLabels = labels(sortIndex);
scoreChangeIndex = [find(diff(sortedScores) ~= 0); ...
    numel(sortedScores)];

cumulativeTP = cumsum(sortedLabels == 1);
cumulativeFP = cumsum(sortedLabels == 0);
tpr = [0; cumulativeTP(scoreChangeIndex) / positiveCount; 1];
fpr = [0; cumulativeFP(scoreChangeIndex) / negativeCount; 1];
```

右侧配标注：

- `sortIndex`：让标签和得分保持对应。
- `scoreChangeIndex`：每个同分组的结束位置。
- `cumsum`：获得每个位置的累计 TP 和 FP。
- 首尾的 `0`、`1`：对应极端阈值。

### 本页重点

代码不要再增加其他行，确保字号足够大。

### 讲述口径

“前三行完成排序和同分组定位，后四行用累计和直接生成 ROC 坐标。相比逐组循环，这个版本更简洁，在北太天元中处理 data3 也更快。”
