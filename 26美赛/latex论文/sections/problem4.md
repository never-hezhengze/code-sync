# 🚀 火箭发射专用 LCA 参数表（可直接算）

## 一、功能单位（统一口径）

| 项目      | 取值                                |
| ------- | --------------------------------- |
| 功能单位 FU | **1 kg payload delivered to LEO** |
| 轨道高度    | 200–500 km                        |
| 结果单位    | kg CO₂-eq / kg payload            |

---

## 二、推进剂燃烧排放因子（发射阶段核心）

### 1️⃣ 液体火箭（主流）

### （1）液氧 / 煤油（LOX/RP-1）

| 排放物               | 排放因子（kg / kg 燃料） |
| ----------------- | ---------------- |
| CO₂               | **3.15**         |
| H₂O               | 1.35             |
| Black Carbon (BC) | **1.0×10⁻³**     |
| NOₓ               | 4.0×10⁻³         |

📌 **黑碳是平流层气候影响的主要来源**

---

### （2）液氧 / 液氢（LOX/LH₂）

| 排放物      | 排放因子（kg / kg 燃料） |
| -------- | ---------------- |
| CO₂      | **≈ 0**          |
| H₂O（平流层） | **9.0**          |
| NOₓ      | 1.0×10⁻³         |
| BC       | 0                |

📌 CO₂ 几乎为零，但**平流层水汽影响需单独加权**

---

### 2️⃣ 固体火箭（SRB）

| 排放物   | 排放因子（kg / kg 推进剂） |
| ----- | ----------------- |
| CO₂   | 0.60              |
| HCl   | **0.20**          |
| Al₂O₃ | **0.15**          |
| NOₓ   | 2.0×10⁻³          |

📌 **臭氧消耗的“重灾区”**

---

## 三、制造阶段材料排放因子

| 材料   | 排放因子（kg CO₂-eq / kg） |
| ---- | -------------------- |
| 铝合金  | **11.5**             |
| 钛合金  | 30.0                 |
| 不锈钢  | 6.1                  |
| CFRP | **29.0**             |
| 电子设备 | 50–70                |

制造阶段排放：
\[
E^{\text{manu}} = \sum_j m_j \cdot EF_j
\]

---

## 四、可重复使用修正参数

| 参数   | 符号                  | 典型值       |
| ---- | ------------------- | --------- |
| 复用次数 | $N_{\text{reuse}}$  | 10–30     |
| 翻修系数 | $f_{\text{refurb}}$ | 0.05–0.15 |

修正公式：
\[
E_{\text{manu}}^{\text{avg}} =
\frac{E_{\text{manu}}}{N_{\text{reuse}}}+ f_{\text{refurb}} \cdot E_{\text{manu}}
\]

---

## 五、平流层高度修正因子（火箭特有）

| 排放物          | 高度修正系数 (f(h)) |
| ------------ | ------------- |
| CO₂          | 1.0           |
| H₂O（平流层）     | **1.5–3.0**   |
| Black Carbon | **5–10**      |
| HCl          | 2.0           |

最终发射排放：
\[
E_i^{\text{launch}} =
m_{\text{fuel}} \cdot EF_i \cdot f_i(h)
\]

---

---

## 七、最终“可直接算”的总公式

### 1️⃣ 单次发射环境影响

\[
EI =
\sum_i\left(\frac{m_i^{\text{manu}}}{N_{\text{reuse}}}+ m_i^{\text{launch}}\right)\cdot CF_i
\]

---

### 2️⃣ 功能单位归一化

\[
EI^{\text{FU}} =
\frac{EI}{m_{\text{payload}}}
\quad
(\text{kg CO₂-eq / kg payload})
\]
