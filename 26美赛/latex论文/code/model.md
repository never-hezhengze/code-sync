# 多目标优化
综合考虑太空电梯与传统火箭实现货物运输
## 目标函数与自变量
优化目标一：任务完成时间$T$
优化目标二：预估总成本$C_total$
自变量：每年发射火箭的次数$x$
## 策略
### 太空电梯：
年吞吐量：$R_SES = 3 * 179000(t/year)$
成本：$C_E = 100($/kg)$
### 火箭：
载荷：$Q_R = 150(t/次)$
成本：$C_R = 500($/kg)$
## 函数表达式
常量：$M = 100000000(t)$
$(R_SES + x * Q_R) * T = M$
$C_total = C_E * R_SES * T + C_R * Q_R * x * 1000$
