# 第八章作业
## 酒店预订策略设计问题解析

### 1. 推导总超订量 q 的最优表达式

**目标**：最大化酒店期望收益，考虑超订补偿成本。

**特征变量**：
- 总客房数 C = 100
- 低价房比例 α = 60%，高价房比例 β = 40%
- 低价房不可退改，空置概率 p_L = 10%
- 高价房可取消，取消概率 p_H = 25%，取消补偿 c_H = 200元
- 超订补偿成本：超订时需支付原房价的150%   

  
**步骤**：
1. 实际入住量随机性：
   - D_L ~ B(60, 0.9)<!--二项分布-->
   - D_H ~ B(40, 0.75)
   - 总入住 D = D_L + D_H

2. 期望收益模型：
E[收益] = 600×E[实际低价房入住] + 1000×E[实际高价房入住]-200×E[高价房取消数]- 1.5×E[超订补偿]  

3. 最优超订量 q*：  
q* = argmax_q {E[收益] - λ×P(D>100+q)}
其中λ为超订补偿成本权重。

## 2. 挤客概率 ≤8% 时的计算

**正态近似**：
- D_L ~ N(54, 4.86)
- D_H ~ N(30, 7.5)
- D ~ N(84, 12.36)

**计算**：
1. 总超订上限：  
挤客概率 P(D>100+q) ≤ 8% ⇒ q ≤ 17间（查标准正态分布表）
2. 独立分配：
- 低价房超订上限：10间
- 高价房超订上限：7间

**比例调整为7:3时**：
- 新分布：D ~ N(85.5, 11.295)
- 重新计算q≤18间，但挤客概率可能因高价房取消率降低而更敏感

## 3. 补偿金≥80%房价时的调整

**新约束**：
- 高价房补偿金 c_H ≥ 800元
- 高价房取消率可能下降（假设降至15%）

**调整后**：
1. 调整高价房模型：D_H ~ N(34, 5.1) D ~ N(88, 9.96)
2. 新超订上限：q ≤ 14间

**建议**：
- 高低价房比例需动态调整，如降低高价房超订比例（因取消率下降，超订风险更高）
- 考虑3:7的保守分配
