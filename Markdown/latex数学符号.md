# LaTeX 数学公式常用命令总结表

| 公式类型 | LaTeX 代码示例 | 效果（渲染后） |
| :--- | :--- | :--- |
| **上下标** | `a^2`, `a_i`, `a_i^2` | \(a^2\), \(a_i\), \(a_i^2\) |
| 分数 | `\frac{a}{b}` | \(\frac{a}{b}\) |
| 根号 | `\sqrt{x}`, `\sqrt[n]{x}` | \(\sqrt{x}\), \(\sqrt[n]{x}\) |
| 求和 | `\sum_{i=1}^{n} x_i` | \(\sum_{i=1}^{n} x_i\) |
| 积分 | `\int_{a}^{b} f(x)\,dx` | \(\int_{a}^{b} f(x)\,dx\) |
| 乘积 | `\prod_{i=1}^{n} x_i` | \(\prod_{i=1}^{n} x_i\) |
| 极限 | `\lim_{x \to 0} \frac{\sin x}{x}` | \(\lim_{x \to 0} \frac{\sin x}{x}\) |
| 无穷 | `\infty` | \(\infty\) |
| 希腊字母 | `\alpha, \beta, \gamma, \pi` | \(\alpha, \beta, \gamma, \pi\) |
| 大写希腊字母 | `\Gamma, \Delta, \Omega` | \(\Gamma, \Delta, \Omega\) |
| 数学关系符 | `\le`, `\ge`, `\ne`, `\approx` | \(\le\), \(\ge\), \(\ne\), \(\approx\) |
| 箭头 | `\to`, `\rightarrow`, `\Rightarrow` | \(\to\), \(\rightarrow\), \(\Rightarrow\) |
| 集合运算 | `\cup`, `\cap`, `\subset`, `\subseteq` | \(\cup\), \(\cap\), \(\subset\), \(\subseteq\) |
| 属于 | `\in`, `\ni`, `\notin` | \(\in\), \(\ni\), \(\notin\) |
| 空集 | `\emptyset` 或 `\varnothing` | \(\emptyset\) |
| 点省略号 | `\cdots`, `\ldots`, `\vdots`, `\ddots` | \(\cdots\), \(\ldots\), \(\vdots\), \(\ddots\) |
| 绝对值 / 范数 | `|x|`, `\|x\|` | \(|x|\), \(\|x\|\) |
| 括号自适应 | `\left( \frac{a}{b} \right)` | \(\left( \frac{a}{b} \right)\) |
| 矩阵 | `\begin{pmatrix} a & b \\ c & d \end{pmatrix}` | \(\begin{pmatrix} a & b \\ c & d \end{pmatrix}\) |
| 行列式 | `\begin{vmatrix} a & b \\ c & d \end{vmatrix}` | \(\begin{vmatrix} a & b \\ c & d \end{vmatrix}\) |
| 多行公式对齐 | `\begin{aligned} x &= a+b \\ y &= a-b \end{aligned}` | \(\begin{aligned} x &= a+b \\ y &= a-b \end{aligned}\) |
| 上/下括号 | `\overbrace{a+b}^{n}`, `\underbrace{a+b}_{n}` | \(\overbrace{a+b}^{n}\), \(\underbrace{a+b}_{n}\) |
| 导数 / 偏导 | `\frac{dy}{dx}`, `\frac{\partial f}{\partial x}` | \(\frac{dy}{dx}\), \(\frac{\partial f}{\partial x}\) |
| 常见函数名 | `\sin`, `\cos`, `\tan`, `\log`, `\ln`, `\max` | \(\sin, \cos, \tan, \log, \ln, \max\) |
| 文本嵌入公式 | `\text{条件}` | \(\text{条件}\) |
| 上下取整 | `\lfloor x \rfloor`, `\lceil x \rceil` | \(\lfloor x \rfloor\), \(\lceil x \rceil\) |
| 模运算 | `\pmod{n}`, `\bmod` | \(\pmod{n}\), \(a \bmod b\) |
| 常用符号 | `\partial`, `\nabla`, `\forall`, `\exists` | \(\partial, \nabla, \forall, \exists\) |
