把货物设计成**“货物类型模板 + 单件货物实例”**两层数据结构。

这样做的好处是：

* 原始数据只存一份，避免重复；
* 展开成单件后，便于逐件装箱；
* 后续极点法、贪心法、局部搜索都能直接调用；
* 最终输出每件货物坐标、姿态时很方便。

---

# 一、推荐的数据结构设计

建议分成 4 类对象：

1. **货物类型 `CargoType`**：描述 G1、G2 这类“模板信息”
2. **单件货物 `CargoItem`**：把数量展开后的每一件具体货物
3. **摆放姿态 `Orientation`**：记录某件货物某种旋转后的尺寸
4. **已装载结果 `PlacedCargo`**：记录装入车厢后的坐标和姿态

---

# 二、货物类型结构 `CargoType`

这个结构用来保存附件里每种货物的原始属性。

```python
from dataclasses import dataclass
from typing import List, Tuple


@dataclass
class CargoType:
    type_id: str                 # 货物编号，如 G1
    category: str                # 货物类别：standard / fragile / oriented
    length: int                  # 原始长度 cm
    width: int                   # 原始宽度 cm
    height: int                  # 原始高度 cm
    weight: float                # 单件重量 kg
    quantity: int                # 数量

    stackable: bool              # 是否允许被堆叠 / 放在下层
    can_rotate: bool             # 是否允许旋转
    fragile: bool                # 是否易碎
    oriented: bool               # 是否定向件
    max_support_pressure: float = 500.0   # 承重上限 kg/m^2
    top_clearance: int = 3       # 车顶安全间隙 cm
```

---

## 这个结构包含的信息

例如：

* `type_id='G3'`
* `category='fragile'`
* `length=70, width=50, height=40`
* `weight=15`
* `quantity=30`

再配合逻辑属性：

* `fragile=True`
* `stackable=False`
* `can_rotate=True/False`
* `oriented=False`

---

# 三、单件货物结构 `CargoItem`

真正做装箱时，不能直接拿“G1 共 80 件”去放，而要展开成 80 个独立对象。
所以需要一个“单件货物实例”。

```python
@dataclass
class CargoItem:
    item_id: str                 # 单件编号，如 G1_001
    type_id: str                 # 所属类型，如 G1
    category: str                # standard / fragile / oriented

    original_size: Tuple[int, int, int]   # 原始尺寸 (l, w, h)
    weight: float                # 单件重量
    volume: int                  # 单件体积 cm^3

    stackable: bool
    can_rotate: bool
    fragile: bool
    oriented: bool

    allowed_orientations: List[Tuple[int, int, int]]  # 所有合法姿态尺寸
```

---

## 为什么要存 `allowed_orientations`

因为后续放置时，经常要做：

* 枚举该货物所有合法姿态
* 检查某个姿态能不能放进某个剩余空间
* 选最优姿态

比如：

* 标准件：6 种姿态
* 定向件：1 种姿态
* 易碎件：可根据你建模时设定为 1 种或若干种

所以这个字段非常重要。

---

# 四、摆放姿态结构 `Orientation`

如果后面代码希望更清晰，可以把姿态单独封装。

```python
@dataclass
class Orientation:
    orient_id: int               # 姿态编号
    size: Tuple[int, int, int]   # 当前姿态尺寸 (l, w, h)
    rotation: str                # 文字说明，如 "LWH", "LHW", "WLH"
```

然后在 `CargoItem` 中写成：

```python
allowed_orientations: List[Orientation]
```

这样好处是更清楚，后面输出“姿态方向”也方便。

# 五、已装载货物结构 `PlacedCargo`

这个结构用于记录一件货物已经被装入车厢后的状态。

```python
@dataclass
class PlacedCargo:
    item_id: str
    type_id: str
    category: str

    x: int
    y: int
    z: int                       # 左后下角坐标

    length: int
    width: int
    height: int                  # 当前姿态下尺寸

    weight: float
    orientation_id: int
    rotation: str                # 当前姿态说明

    support_by: str | None = None    # 支撑它的货物编号，若在底板上则为 None
    truck_id: str | None = None      # 属于哪辆车
```

---

## 为什么这个结构必要

因为题目最终要求输出：

* 每件货物的摆放坐标
* 每件货物的姿态方向

这些都可以直接从 `PlacedCargo` 里导出。

另外后面做：

* 碰撞检测
* 支撑关系检查
* 承重统计
* 可视化绘图

也都很方便。

# 八、为本题生成合法姿态的函数

这个函数很关键，后续一定会用到。

```python
def generate_orientations(length: int, width: int, height: int, category: str) -> List[Orientation]:
    dims = [
        (length, width, height, "LWH"),
        (length, height, width, "LHW"),
        (width, length, height, "WLH"),
        (width, height, length, "WHL"),
        (height, length, width, "HLW"),
        (height, width, length, "HWL"),
    ]

    # 去重，避免边长相同导致重复姿态
    unique = []
    seen = set()
    for l, w, h, name in dims:
        if (l, w, h) not in seen:
            seen.add((l, w, h))
            unique.append((l, w, h, name))

    # 定向件：只保留原始姿态
    if category == "oriented":
        unique = [(length, width, height, "LWH")]

    result = []
    for i, (l, w, h, name) in enumerate(unique):
        result.append(Orientation(i, (l, w, h), name))
    return result
```

# 十、展开为单件货物列表

```python
def expand_cargo_items(cargo_types: dict) -> List[CargoItem]:
    items = []
    for type_id, cargo in cargo_types.items():
        orientations = generate_orientations(
            cargo.length, cargo.width, cargo.height, cargo.category
        )
        for i in range(1, cargo.quantity + 1):
            item_id = f"{type_id}_{i:03d}"
            volume = cargo.length * cargo.width * cargo.height
            items.append(
                CargoItem(
                    item_id=item_id,
                    type_id=type_id,
                    category=cargo.category,
                    original_size=(cargo.length, cargo.width, cargo.height),
                    weight=cargo.weight,
                    volume=volume,
                    stackable=cargo.stackable,
                    can_rotate=cargo.can_rotate,
                    fragile=cargo.fragile,
                    oriented=cargo.oriented,
                    allowed_orientations=orientations
                )
            )
    return items
```

# 十二、最推荐的设计结论

如果你想后续代码最稳，我建议你采用下面这一套：

* `CargoType`：存 G1-G5 模板信息
* `CargoItem`：存展开后的每件货物
* `Orientation`：存合法姿态
* `PlacedCargo`：存已装车结果
