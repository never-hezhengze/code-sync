# 问题二 Python代码结构设计

为求解问题二中的“多车型组合 + 货物分配 + 三维装箱”联合优化问题，本文采用分层启发式算法进行程序实现。整体代码结构划分为多个功能模块，各模块之间层次清晰、职责明确，便于扩展与调试。

---

## 一、整体架构

问题二代码整体采用三层结构：

1. **上层：车型组合搜索层**
2. **中层：货物分配优化层**
3. **下层：单车三维装箱验证层**

其逻辑流程如下：

```
读取数据
→ 生成车型组合
→ 货物初始分配
→ 单车装箱验证
→ 大邻域搜索优化
→ 输出最优方案
```

---

## 二、模块划分

### 1. 数据读取模块

负责读取并初始化问题所需数据。

#### 功能：
- 读取车型参数（尺寸、载重、成本）
- 读取货物数据（尺寸、重量、类别、数量）
- 将货物展开为单件对象列表

#### 典型函数：

```python
load_truck_types()
load_cargo_types()
expand_cargo_items()
```

---

### 2. 车型组合生成模块

负责生成候选车辆组合。

#### 功能：
- 枚举不同数量的车辆组合
- 为每辆车分配车型（1或2）
- 支持两种目标模式：
  - 最少车辆数
  - 最低运输成本

#### 典型函数：

```python
generate_truck_type_combinations(max_k, mode)
```

#### 输出形式：

```python
(1, 2, 2)   # 表示三辆车：车型1、车型2、车型2
```

---

### 3. 货物分配模块

负责将货物分配到不同车辆。

#### 功能：
- 按难装程度排序货物：
  - 易碎件优先
  - 定向件次之
  - 标准件最后
- 同类按体积、重量降序排序
- 贪心分配到车辆中

#### 典型函数：

```python
initial_assign_items_to_trucks(items, truck_instances)
```

#### 输出形式：

```python
groups = [
    [item1, item5, item9],   # 第1辆车
    [item2, item3],          # 第2辆车
]
```

---

### 4. 单车装箱验证模块

负责对每辆车进行三维装箱验证。

#### 功能：
- 调用问题一单车装箱算法
- 检查是否满足：
  - 非重叠约束
  - 姿态约束
  - 易碎件约束
  - 定向件约束
  - 承重约束
  - 支撑约束
- 返回装箱结果

#### 典型函数：

```python
validate_groups_with_single_truck_packer(groups, truck_instances)
```

#### 输出：

```python
PackingResult:
    - placed_items
    - unplaced_items
    - coordinates
    - score
```

---

### 5. 大邻域搜索模块（LNS）

用于优化货物分配，提高解质量。

#### 功能：
- 跨车辆重分配货物
- 减少尾部低利用率车辆
- 提升整体装载均衡性

#### 基本步骤：

1. 随机选取1～2辆车
2. 移除部分货物（优先大件或难装件）
3. 将移除货物重新分配到所有车辆
4. 再次进行单车装箱验证
5. 若方案更优则接受

#### 典型函数：

```python
improve_assignment_lns(groups, truck_instances, max_iters=100)
```

---

### 6. 主求解模块

根据不同目标定义两个主函数。

---

#### （1）最少车辆数问题

```python
solve_problem_2_min_vehicle(items, truck_types)
```

#### 执行流程：

```
计算理论下界 LB
→ 从 K = LB 开始枚举
→ 枚举车型组合
→ 货物分配
→ 单车装箱验证
→ 若可行则返回
→ 否则继续增大 K
```

---

#### （2）最低运输成本问题

```python
solve_problem_2_min_cost(items, truck_types)
```

#### 执行流程：

```
生成车型组合集合
→ 按总成本排序
→ 对每个组合：
    → 货物分配
    → 单车装箱验证
    → 若可行则返回
```

## 四、代码执行流程总结

完整执行流程如下：

```
读取数据
→ 选择目标函数（车辆数 or 成本）
→ 生成车型组合
→ 货物初始分配
→ 单车装箱验证
→ 若不可行：
      → 更换组合 或 调整分配
→ 若可行：
      → 进入LNS优化
→ 输出最优方案：
      - 车型组合
      - 车辆数
      - 总成本
      - 装箱坐标与姿态
```

---

## 五、算法特点

本代码结构具有如下特点：

1. **分层求解**：将复杂问题拆解为组合优化 + 装箱验证；
2. **复用性强**：直接复用问题一单车装箱算法；
3. **可扩展性好**：可方便增加新约束或新车型；
4. **求解效率高**：避免直接求解大规模混合整数模型；
5. **结果可解释性强**：输出完整装箱方案（坐标 + 姿态）。

---

## 六、总结说明

问题二的代码实现并非直接求解完整数学模型，而是基于模型结构设计分层启发式算法：

- 上层：车型组合搜索
- 中层：货物分配优化
- 下层：三维装箱验证

该方法在保证模型约束合理表达的同时，能够在有限时间内获得高质量可行解，是处理多车型三维装箱问题的一种有效工程实现方式。
